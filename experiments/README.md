# Эксперименты фильтра SMS-спама

В каталоге сохранены 63 фактически выполненных offline-запуска. Каждый JSON содержит полную
конфигурацию, реализованный баланс классов после дедупликации, размеры split, выбранный
precision-порог, метрики TF-IDF модели и keyword baseline, профиль разреженной матрицы и
диагностики по длине сообщений.

## Состав запусков

| Семейство | JSON | Что проверяется |
| --- | ---: | --- |
| Precision target | 10 | Рабочие точки от 80% до 99% precision |
| Class imbalance | 10 | Разные исходные количества ham и spam с учётом дедупликации |
| Vectorizer | 15 | Word, char и объединённый TF-IDF, n-grams, `C`, число признаков |
| Obfuscation | 10 | Leetspeak, пробелы, пунктуация и смешанный регистр |
| Message length | 8 | Обрезка, нейтральный хвост и удвоение текста |
| Seed stability | 10 | Полный повтор split, fitting и выбора порога на четырёх seed |

Всего выполнено 35 запусков word TF-IDF, 14 char TF-IDF и 14 объединённых моделей.

## Наблюдения

- Precision-ограничение выполнено в **63 из 63** основных запусков. Медианная test precision
  равна **1.00**, медианный recall — **0.909**.
- Во всех запусках TF-IDF не уступил keyword baseline по average precision; медианный прирост
  составил **0.173**.
- На синтетическом корпусе test average precision часто достигает **1.00** для всех трёх
  представлений. Поэтому этот benchmark проверяет pipeline и стресс-поведение, но не позволяет
  честно выбрать лучший vectorizer по PR-AUC.
- В imbalance-сценариях фактическая доля spam после дедупликации менялась от **13.48%** до
  **50.00%**. JSON отдельно сохраняет запрошенные и фактически полученные количества.
- Самое большое наблюдавшееся падение detection rate после обфускации составило **0.727**.
  Смешанный регистр не изменил результат из-за lowercase-нормализации, тогда как пробелы,
  пунктуация и leetspeak заметно снизили вероятность spam.
- Обрезка до 24 символов снизила recall на **0.917** для word TF-IDF и на **0.833** для char
  TF-IDF. Простое удвоение текста recall не изменило.
- В 10 stability-отчётах выполнено 40 независимых повторов. Все 40 достигли заданного
  precision; медианное стандартное отклонение recall равно **0.075**, порога — **0.024**.

Срезы длины и stress-дельты считаются внутри одного holdout, поэтому их можно сравнивать с
чистым состоянием соответствующего запуска. Метрики разных seed не следует ранжировать как
результаты на одной и той же выборке.

## Воспроизведение

Пример проверки precision-порога:

```bash
PYTHONPATH=src python -m sms_spam_filter.experiments \
  --output /tmp/sms-precision.json \
  --label local-precision-check \
  --seed 1101 \
  --ham-count 120 \
  --spam-count 48 \
  --min-precision 0.95
```

Пример char TF-IDF с обфускацией:

```bash
PYTHONPATH=src python -m sms_spam_filter.experiments \
  --output /tmp/sms-obfuscation.json \
  --label local-obfuscation-check \
  --seed 4119 \
  --ham-count 140 \
  --spam-count 56 \
  --vectorizer char_tfidf \
  --max-features 3000 \
  --obfuscation leetspeak
```

Эксперименты используют локальные шаблонные сообщения. Они подтверждают инженерное поведение
pipeline, но не заменяют оценку на зафиксированной версии UCI SMS Spam Collection или на
современном потоке сообщений.
